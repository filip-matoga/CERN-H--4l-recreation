# CERN-H--4l-recreation

This project cleans a dataset taken from the CERN Open Data dataset, selects high quality collision events which could
stem from a H –> ZZ* –> 4l decay, and plots an invariant mass distribution for a signal, and a background file.
The background file represents collision events which are ZZ –> 4l decays – the distinction is key, as this can easily
be mistaken for a Higgs decay due to the misleading ZZ –> 4l decay. The key difference, is that in order for the 4 leptons
to stem from a Higgs decay, one of the Z bosons must be a virtual Z boson, of mass ~~ 30 GeV.
